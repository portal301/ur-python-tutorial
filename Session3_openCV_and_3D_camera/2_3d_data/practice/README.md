# Practice: 클릭한 점 위로 로봇 보내기

RealSense 화면에서 점을 클릭하면, 로봇이 그 점의 **30cm 위**로 이동합니다.
3번 예제(`3_click_to_3d.py`)에서 구한 **카메라 기준 3D 좌표**를 **로봇 베이스 기준 좌표**로 바꾸는 것이 핵심입니다.

- 문제: `practice/1_click_move.py` (`# TODO` 4곳)
- 정답: `answer/1_click_move.py`

```bash
cd 2_3d_data
python practice/1_click_move.py
```

## 조작 방법

| 키 | 동작 |
|---|---|
| 마우스 왼쪽 클릭 | 목표 계산 (아직 움직이지 않음, 화면에 + 표시) |
| `m` | 목표로 이동 |
| `c` | 목표 취소 |
| 스페이스 | 정지 명령 |
| `q` | 종료 |

## 안전 수칙

- 펜던트를 **원격제어(Remote) 모드**로 두세요.
- 클릭하면 목표 위치와 이동 거리가 먼저 출력됩니다. **값을 확인한 뒤에** `m`을 누르세요.
- 이상하면 바로 **스페이스(정지)** 또는 펜던트 비상정지 버튼을 누르세요.
- 이동 속도는 `SPEED_V = 0.05` (5cm/s)로 느리게 설정되어 있습니다. 함부로 올리지 마세요.
- `TCP_CAMERA`는 이 카메라가 툴에 붙은 위치·각도입니다. 장비마다 다르므로 실습 장비에 맞는 값인지 확인하세요.

| 구역 | 함수 | 하는 일 |
|---|---|---|

## 좌표 변환 이해하기

같은 점이라도 **어디를 기준으로 보느냐**에 따라 좌표가 달라집니다.

```
카메라 기준 점  ──(카메라가 툴에 붙은 위치·회전)──▶  툴 기준 점  ──(툴의 지금 위치·회전)──▶  베이스 기준 점
   p_cam              TCP_CAMERA                       p_tool          pose (read_pose)               point
```

좌표 변환은 항상 **회전한 뒤 이동**합니다.

```python
새 좌표 = 회전행렬 @ 점 + 위치
```

- `cv2.Rodrigues(회전벡터)`: UR이 쓰는 회전 표현 `(rx, ry, rz)`를 3x3 **회전 행렬**로 바꿔 줍니다.
- `@`: 행렬 곱셈 연산자입니다. `R @ p`는 점 `p`를 회전시킵니다. (`*`와 다릅니다)
- `R_cam_to_tool`: 카메라 좌표를 툴 좌표로 바꾸는 회전
- `R_tool_to_base`: 툴 좌표를 베이스 좌표로 바꾸는 회전
