# Session6: 종합 미션 (M/R 물체 Pick and Place)

6일차에는 지금까지 배운 로봇 제어, 그리퍼, 비전 인식을 모두 사용해서 미션을 해결합니다.
테이블 위에 윗면에 `M` 또는 `R` 글자가 적힌 물체들이 놓여 있습니다.

## 준비물
- Day 5에서 학습한 M·R OBB 모델
- 참고 코드: `Session5_AI_robot/practice/4_straighten_pick.py`

## 미션 1: 정렬하기
- 삐뚤어진 물체를 OBB로 보고 똑바로 세워 놓기
- `R M` 순서로 놓인 물체를 `M R` 순서로 바꿔 놓기

## 미션 2: 단어 만들기
- 주어진 문자열(예: `MRRM`)대로 물체를 일렬로 놓기

## 미션 3: 복구하기
- 사람이 물체를 섞어 놓으면 다시 찾아서 원래 배치로 되돌리기
