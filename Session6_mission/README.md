# Session6: 종합 과제 (Pick and Place)

6일차에는 지금까지 배운 로봇 제어, 그리퍼, 비전 인식을 모두 사용해서 과제를 해결합니다.
코드는 직접 만듭니다. Day5 `practice/4_straighten_pick.py`를 복사해서 시작하세요.

## 과제: 정렬하기

- 테이블 위에 삐뚤어지게 놓인 물체들을 찾아서, 정해 둔 칸에 하나씩 똑바로 놓아 보세요.
- 도전: 놓인 순서를 바꿔 보세요. (예: `R M` → `M R`)
- 힌트: 물체가 여러 개 → 반복문 / n번째 칸 위치 = 첫 칸 위치 + n × 칸 간격

## 기타

- 단어 만들기: 주어진 문자열(예: `MRRM`)대로 물체를 일렬로 놓기
- 복구하기: 사람이 섞어 놓은 물체를 원래 배치로 되돌리기
