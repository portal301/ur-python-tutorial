# Extra: Docker로 가상 UR 로봇(URSim) 사용하기
실물 로봇 없이 내 PC에서 가상 UR 로봇을 띄우고, Day 1에서 만든 코드를 그대로 돌려보는 구성입니다.

## Lecture 1: Docker 기초
- Docker Desktop 설치.
- 이미지와 컨테이너, 포트 연결(`-p`), 폴더 연결(`-v`) 네 가지 개념만 짧은 예제로 익히기.

## Lecture 2: URSim 실행
- UR 공식 시뮬레이터 이미지 실행.
- 브라우저에서 PolyScope를 열고 로봇 켜기, 화면 둘러보기.

## Lecture 3: Day 1 코드를 가상 로봇에 연결
- Day 1 Lecture 2 스크립트 전송 코드를 가상 로봇에 연결.
- Day 1 Lecture 3 소켓 통신 코드(로봇 → PC 접속)를 가상 로봇에 연결.

## 기대효과
- 실물 로봇 없이도 집이나 회사에서 로봇 코드를 연습할 수 있는 환경 확보.
- 실물에 보내기 전에 가상 로봇에서 먼저 시험하는 습관.
