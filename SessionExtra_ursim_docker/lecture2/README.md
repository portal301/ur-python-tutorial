# Lecture 2

## 강의 목표

- Docker로 URSim(UR 공식 시뮬레이터)을 실행합니다.
- 브라우저에서 PolyScope(티치 펜던트 화면)를 열고 로봇을 켭니다.

## 1. URSim 실행

터미널(PowerShell)에서 아래 명령을 실행합니다. 처음에는 이미지(약 1GB)를 내려받느라 시간이 걸리고, 실행 후 PolyScope가 뜨기까지 1~2분 걸립니다.

```powershell
docker run --rm -it -p 5900:5900 -p 6080:6080 -p 29999:29999 -p 30001-30004:30001-30004 --name ursim universalrobots/ursim_e-series
```

| 옵션                         | 뜻                                                   |
| ---------------------------- | ---------------------------------------------------- |
| `--rm`                       | 컨테이너를 끄면 자동으로 지움                        |
| `-it`                        | 터미널에 로그를 보여주고 `Ctrl + C` 로 끌 수 있게 함 |
| `-p 6080:6080`               | 브라우저로 PolyScope 보기                            |
| `-p 5900:5900`               | VNC 프로그램으로 PolyScope 보기                      |
| `-p 30001-30004:30001-30004` | 스크립트 전송·상태 수신 포트 (Day 1에서 쓰던 포트)   |
| `-p 29999:29999`             | 대시보드 서버                                        |
| `--name ursim`               | 컨테이너 이름                                        |

- 기본 모델은 UR5e 입니다. 다른 모델은 `-e ROBOT_MODEL=UR10` 처럼 지정합니다.
- 끌 때는 터미널에서 `Ctrl + C` 를 누릅니다.

### 만든 프로그램 남기기 (선택)

`--rm` 때문에 컨테이너를 끄면 PolyScope에서 만든 프로그램도 사라집니다. Lecture 1의 폴더 연결을 씁니다.

```powershell
docker run --rm -it -p 5900:5900 -p 6080:6080 -p 29999:29999 -p 30001-30004:30001-30004 -v ${HOME}/.ursim/programs:/ursim/programs --name ursim universalrobots/ursim_e-series
```

## 2. PolyScope 열기

1. 브라우저에서 `http://localhost:6080/vnc.html` 에 접속합니다. 터미널 로그에 `172.17.0.2` 같은 주소가 찍혀도 내 PC에서는 `localhost` 로 접속합니다.
2. **연결(Connect)** 을 누르면 PolyScope 화면이 보입니다.
3. 왼쪽 아래 빨간 버튼 → **켜기(ON)** → **시작(START)** 을 눌러 로봇 전원을 켜고 브레이크를 풉니다.
4. 왼쪽 아래가 초록색 **정상(Normal)** 이 되면 준비 완료입니다.

> 실물과 달리 네트워크(DHCP) 설정은 필요 없습니다.

## 3. 둘러보기

- **이동** 탭에서 화살표로 로봇을 움직여 보고, 화면의 TCP 좌표와 관절 값이 바뀌는 것을 확인합니다.
- 충돌해도 다치지 않으므로 마음껏 움직여 봅니다.
